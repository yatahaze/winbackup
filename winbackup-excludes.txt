# winbackup-excludes.txt -- what winbackup.sh skips. Edit freely; one rsync pattern per line.
#
# Patterns are matched against paths relative to the ROOT OF EACH DRIVE, e.g.
#   Users/ryan/AppData/Local/Temp/somefile
# Rules of thumb (these are rsync exclude patterns):
#   dir/                 trailing slash = directories only
#   *.tmp                no slash = matches a file/folder NAME anywhere in the tree
#   AppData/Local/Temp/  has a slash = matches that path sequence anywhere in the tree
#   AppData/**/Cache/    ** crosses folder boundaries: any "Cache" folder anywhere under AppData
#   /ProgramData/x/      leading slash = anchored to the drive root
# Lines starting with # are comments. The copy actually used by a run is saved into the
# backup folder as _excludes_used.txt, and the biggest things skipped are listed in
# _excluded_summary.txt so you can check nothing important was dropped.
